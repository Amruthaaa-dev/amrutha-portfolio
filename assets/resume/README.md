# resume/

## Add your resume here

Save your CV as:

```
assets/resume/Amrutha-Haridas-Resume.pdf
```

That exact filename is already wired to two places:

- The **Download Resume** button in the hero
- The **Resume** link in the footer

Both use the `download` attribute, so the browser saves the file rather than
opening it in a tab.

If you prefer a different filename, update the two `href` values in
`index.html` — search for `Amrutha-Haridas-Resume.pdf`.

**Tip:** keep the PDF under 1 MB. Recruiter ATS systems and email filters
often choke on larger files.
