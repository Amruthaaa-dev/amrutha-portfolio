Let's build something

I am a passionate Software Engineer from Kerala, India, specializing in PHP, Laravel, CodeIgniter, Shopify and REST API Development.

I enjoy building scalable ERP solutions, eCommerce applications and high-performance web platforms with clean architecture and modern UI. Most of my work lives where business logic gets heavy — inventory that has to reconcile, sales and purchase flows that must never drift, dashboards that stay fast when the tables get large.

My approach is simple: model the domain properly, keep queries honest, ship interfaces that feel effortless, and leave code the next engineer can read without a map.

Clean Architecture

Layered services, thin controllers, predictable data flow — features stay cheap to add.

Database First

Normalized schemas, indexed access paths and queries that hold up past a million rows.

Performance

Caching, eager loading, payload discipline. Fast is a feature, not an optimization phase.

Reliable Delivery

Git discipline, staged deployments, monitoring after release — not just until merge.
